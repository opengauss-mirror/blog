# 数据库安装提示无法执行二进制文件怎么办？

**背景介绍**：

在使用arm64安装包执行数据库安装时，提示无法执行二进制文件。

**报错内容**：

```
Process exited with status 126: bash :/home/omm1/uqbar/app/bin/gs_initdb: cannot execute binary file: Exec format error
```

**报错原因**：安装包有问题，安装包和操作系统不适配。

**解决办法**：

1. 执行`uname -a`查询发现操作系统为麒麟V10 x86系统。

2. 用x86安装包替换掉arm64安装包即可安装成功。
