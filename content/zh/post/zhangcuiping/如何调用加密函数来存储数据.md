# 如何调用加密函数来存储数据

1. 创建表，插入数据，并查看。

   ```
   Create table t_datastore_encrypt (id_number int, name text, credit_card varchar(19), hostmail varchar(30), telnum varchar(20), c_password character(50));
   Insert into t_datastore_encrypt values (1, 'alsa', '6211998567000001', 'alsa@enmotech.com','17790871245', 'gauss@123');
   Insert into t_datastore_encrypt values (2, 'lisa', '6211998967000002', 'lisa@enmotech.com','17780871205', 'gauss@123');
   Select * from t_datastore_encrypt;
   ```

2. 修改表，插入数据，调用加密函数存储数据,并查看表。

   ```
   Alter table t_datastore_encrypt modify c_password character(100);
   Insert into t_datastore_encrypt values (3, 'lieo', '6211998967000003', 'lieo@enmotech.com','17780871206',gs_encrypt_aes128('3','gauss@123456'));
   Select * from t_datastore_encrypt;
   ```

   会发现密码列的数据以加密形式存储。
